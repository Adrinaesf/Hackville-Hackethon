# MedEasy

MedEasy is an AI-powered medication management web application developed during a 24-hour hackathon to make medication information easier to understand and manage, particularly for senior citizens.

🏆 **Award: Best Use of MongoDB Atlas**

## Overview

Medication information can often contain complex medical terminology that is difficult to understand. MedEasy provides a more accessible way for users to manage medication information and receive simplified explanations.

The application combines a web interface, database storage, and an LLM-powered feature for simplifying medical terminology.

## Features

* 💊 Medication management
* 🤖 AI-powered explanations of medical terminology
* ♿ Accessibility-focused design
* 🗄️ Cloud database storage with MongoDB Atlas
* 🌐 Web-based interface

## Tech Stack

* **Python**
* **Flask**
* **JavaScript**
* **HTML/CSS**
* **MongoDB Atlas**
* **Gemini API**

## How It Works

1. Users interact with the web application to manage their medication information.
2. Medication data is stored using **MongoDB Atlas**.
3. The **Gemini API** is used to simplify complex medical terminology into easier-to-understand explanations.
4. The resulting information is presented through the web interface.

## Hackathon

MedEasy was developed as part of a **24-hour hackathon**.

Our team worked under a limited time constraint to design, develop, integrate, and present a working prototype.
